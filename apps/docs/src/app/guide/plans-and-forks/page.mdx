# Plans, forks and visuals

<p className="lead">A chat keeps a plan you and the agent both edit. You can fork a conversation to try another way, and an agent can answer with a page instead of text.</p>

## Plans

When an agent makes a plan, a pill above the composer says **New plan**. Open it to see the plan beside the chat, with the step the agent works on now.

<PlanMockup />

A plan is a list of steps, or a test plan with tests that pass or fail. You work in it alongside the agent:

- Mark a step as done, failed, skipped, blocked or any other state. The agent never overwrites a state you set.
- Add a note to a step, such as what went wrong or what to change.
- Filter on open steps or on issues, and collapse what is done.
- **Send results to chat** hands the plan's results back to the agent as a message.
- **Copy as Markdown** copies the whole plan.

An agent can lock a step so that only it checks that step. **Unlock** takes the lock off.

A plan belongs to its chat. Clearing the chat clears its plans too.

## Forks

Open the menu of a turn and choose **Fork conversation…** to continue from that point in a new chat, while the original stays as it is. Ruimte sends nothing until you write the first message.

The fork dialog asks:

- **Fork into.** A node beside the original, with a line from it, or a new view.
- **Continue with.** The same CLI and model, or another one. Another CLI gets the last part of the conversation as text, and can read the rest in the original.
- **Account.** Another account of the same CLI.
- **Work in a git worktree.** The fork gets its own branch and checkout, so its changes stay apart from the original's. You can take uncommitted files along, or start from the files as they were after that turn.
- **Machine.** Fork onto another machine of your account. See [Work on another machine](/guide/other-machines).

A fork shows a **Fork** pill that leads back to the original. **Summarize for the original** sends a summary of what the fork found back to the chat it came from.

## Visual replies

An agent can put a page above its reply: a chart, a table, a diagram or a mockup. **Open large** shows it full size. The page runs closed off from the rest of the app and cannot read your files.

Visual replies are on by default. Turn them off per machine under Settings, Agents, Visual replies, and agents answer in text.

A reply can also hold a map with places on it. Settings, Chats, Map tiles decides whether maps load their tiles from Ruimte's map service, which also needs you to be signed in. Without tiles, a map shows only an outline and its places.

## Images and 3D models

An agent can show an image or a 3D model (glTF, USDZ or STL) in the thread. Save an image it made into the project with **Save image to project**. A page or image you want to keep goes to Output. See [Routines and Output](/guide/routines#output).
