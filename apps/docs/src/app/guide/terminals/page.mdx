# Terminals

<p className="lead">A terminal runs your shell, or an agent CLI in its own interface. It keeps running on the machine when you close the window.</p>

## A shell

A new terminal (`Option+T` on a canvas) opens your usual shell in the project folder. It is a full terminal: colors, mouse, full-screen programs and 10,000 lines of scrollback.

The session lives on the machine, not in the window. Close the window, reload it or open the project on another device, and the terminal is where you left it, with its scrollback. When a shell exits, the terminal says so and offers **Restart**.

## An agent in a terminal

Pick an agent CLI under Agents on an empty canvas, or run **New Claude Code terminal** (or another CLI) from the command palette. The terminal starts the CLI in its own interface, as it would in any other terminal. You type, approve and answer in that interface.

The header shows what the agent is doing:

| Status | Meaning |
| --- | --- |
| Running | The agent is working. |
| Needs you | It asks a question or wants permission, in its own prompt. |
| Idle | It finished its turn and waits for your next message. |
| Error | Its turn ended with an error. |
| Sub-agents working | Its turn is over, but agents it started still work. |
| Session ended | The CLI or shell has exited. |

The status needs a few lines in the CLI's own settings, which Ruimte adds once you allow it (Settings, Agents, Agent status in terminals). Without them, a terminal agent shows no status and never asks for your attention. Antigravity only reports a finished turn.

Ruimte never answers a terminal agent's prompt for you. When one waits, Ruimte shows that it needs you, with a **Go to terminal** button, and you answer in the terminal.

If Ruimte or the machine restarts, an agent's terminal comes back with **Resume**, which picks up the conversation where the CLI left it.

New terminal agents start in the permission mode under Settings, Agents, Terminal agents start in. See [AI chats](/guide/chats#permissions) for what each mode allows.

## Links, ports and files

- Hover a link to see where it goes. `Cmd+click` opens it. Settings, Terminal decides whether links open in your system browser (the default) or in a browser node beside the terminal.
- An address on `localhost` only means something on the terminal's own machine. Ruimte opens it only when that machine is the computer in front of you.
- On a Mac, a terminal shows a badge such as `:5173` for each port its programs listen on. Click it to open that page in a browser node beside the terminal.
- Drop a file on a terminal to type its path.

## Commands from the project file

A terminal saved in a shared view can carry a command to start with, such as `bun dev`. A teammate's command never runs on your machine by itself. The terminal shows **Run `bun dev`?** and waits until you press **Run**. Once you approve it, it starts on its own from then on, until the command changes.
