# Testing and packing

<p className="lead">`ruimte extension test` runs your tests with Bun against a fake Ruimte, so a test needs no window and no machine.</p>

```bash
bun run test
```

It runs `bun test` with the extension API answered by a fake host. Your `client/index.ts` loads as it would in Ruimte, and `@ruimte/extension/testing` reads what it defined.

## What it defined

```ts
import { expect, test } from 'bun:test';
import { definitions, slotAnswer } from '@ruimte/extension/testing';
import '../client/index';

test('summarize shows for two nodes or more', () => {
    const action = definitions().find((each) => each.kind === 'action');
    const summarize = action?.definition as { slots: object };

    const one = slotAnswer(summarize, 'selectionBar', {
        nodes: [nodeA]
    });
    const two = slotAnswer(summarize, 'selectionBar', {
        nodes: [nodeA, nodeB]
    });

    expect(one).toBe(false);
    expect(two).toBe(true);
});
```

`definitions()` lists every `define*` call in order, and `slotAnswer` asks a slot what it shows for a context.

## A surface

`renderSurface` draws a component to a string, with `server` standing in for your server part:

```ts
import { renderSurface } from '@ruimte/extension/testing';
import Main from '../client/Main';

test('the panel greets', () => {
    const html = renderSurface(Main, {
        server: {
            greeting: async () => 'Good morning'
        }
    });

    expect(html).toContain('Good morning');
});
```

## Packing

```bash
bun run pack
```

`pack` builds the client and server parts with Bun and writes a `.rex`. It refuses a pack that would not load:

- a client part that imports from `server/`, or a server part that imports from `client/`,
- an icon that is not an SVG of at most 64 KB at `assets/icon.svg`,
- a theme whose tokens or stylesheet break the rules in [Themes](/extensions/themes).

Imports of `@ruimte/extension` and React become what Ruimte supplies, so they add nothing to the pack.

## The command line

```text
ruimte extension create    scaffold a project
ruimte extension dev       build on save and load it into the running Ruimte
ruimte extension test      bun test against a fake host
ruimte extension pack      build a .rex
ruimte extension logs      what the server part wrote
```
