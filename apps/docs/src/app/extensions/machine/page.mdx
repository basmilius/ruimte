# The project and the machine

<p className="lead">The client part reads and changes the project in front: its canvas, views, files, git and databases, and what runs on the machine.</p>

Every call works on the project of the window. Reading what is on screen needs no permission; the rest names its permission below.

## What is on screen

```ts
const selection = useSelection();
const terminals = useNodes((node) => node.kind === 'terminal');
const project = useProject();
```

`useNode`, `useViews`, `useActiveView`, `useMachine` and `useTheme` read the rest. `useEvent('node.added', listener)` hears changes in a component and `onEvent` outside one; [the reference](/extensions/reference/client#ClientEvents) lists every event.

## The canvas

With `canvas.write`:

```ts
const note = canvas.createNote({
    title: 'Summary',
    text,
    near: selection
});
canvas.link(selection[0], note);
canvas.arrange(selection, 'grid');
```

`canvas` also creates file, browser and your own nodes, groups and moves nodes, and links and unlinks them. `canvas.remove` asks the person first and answers whether they agreed. `select` and `reveal` need no permission.

With `views.write`, `views.createCanvas` and `views.rename` change views; `views.open` needs nothing.

## Files and git

Paths are relative to the project folder, and nothing outside it is reachable.

```ts
const readme = await files.readText('README.md');
const stop = files.watch('src', () => refresh());
```

`files.readText` and `list` need `files.read`, `write` needs `files.write`, and `open` shows a file in the editor without either. `git.status`, `git.diff` and `git.log` need `git.read`.

## Databases

With `database.read`, an extension runs one `SELECT` or `WITH` statement on a read-only session, as an agent does:

```ts
const [connection] = await database.connections();
const { columns, rows } = await database.query(
    connection.id,
    'select count(*) from orders'
);
```

## What the machine runs

Each of these calls the machine action of the same name, so `launches.start({ name: 'web' })` is `launch.start`, and answers its output.

| Object | Calls | Permissions |
| --- | --- | --- |
| `launches` | `list`, `read`, `start`, `restart`, `stop` | `launches.read` to read, `launches.run` for the rest |
| `routines` | `list`, `run`, `pause`, `resume` | `routines.read` to list, `routines.run` for the rest |
| `artifacts` | `list`, `read`, `publish` | `artifacts.read` to read, `artifacts.write` to publish |
| `browser` | `inspect`, `navigate`, `back`, `forward`, `reload`, `screenshot` | `browser.control` |
| `devices` | `list`, `inspect`, `screenshot`, `tap`, `launch` | `devices.control` |

An agent may only drive a browser or device it has a line to. An extension has no node for a line to reach, so with the permission it drives any of the project's.

## Terminals

`terminals.read(node)` returns what a terminal shows, with `terminals.read`. `terminals.open()` opens a shell beside the nodes you name, with `canvas.write`. Nothing types into a terminal: only a person does.

## Context

With `context.read`, `context.read({ nodes })` answers what an agent would read of those nodes along a line: a note's text, a file, a terminal's screen.

## Talking to the person

`host` shows things to the person and asks them things:

```ts
host.notify('Saved', {
    action: {
        title: 'Open',
        run: () => files.open('notes.md')
    }
});

const confirmed = await host.confirm({
    title: 'Remove 3 notes?',
    body: 'This cannot be undone.',
    danger: true
});
```

`host.prompt`, `host.pick`, `host.pickFolder`, `host.openUrl`, `host.copy` and `host.openSettings` do what their names say.

## Usage

With `usage.read`, `useUsageLimits()` reads how much of each plan window the person used, from 0 to 1.
