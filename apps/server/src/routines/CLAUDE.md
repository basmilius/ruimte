# Routines

When routines run on the clock is a product rule in the root `CLAUDE.md`; the `routine-run` entry is in `apps/server/src/outbox`.

- A routine is work that starts once at a set time or on repeat, in one project: an agent with a prompt, a shell command, or a project launch. Its definition lives in `.ruimte/routines.json` (shared, committed by a team) or `.ruimte/private/routines.json` (one person's). The private file also keeps, per routine, what is one person's on this machine: the account, a pause, a refusal (`local`). An entry this release cannot read is kept and written back as it stands.
- A routine runs only as a person on this machine approved it as it stands now: its digest (`digestOf`) under `$RUIMTE_HOME/command-approvals` with the key `routine:<id>`. A person's `routine.save` approves what it writes. A verb, git, a hand edit or anything else never does, so a change from any of them asks again. An agent's save is narrowed to its own mode ceiling first, and the chat that made it is recorded under `$RUIMTE_HOME/routine-authors` for the approval card.
- A routine runs whether or not a client has its project open, for every project in the machine's register; pausing is how a person stops it. A removed project runs nothing.
- Each routine owes at most one `routine-run` entry, due at its next time. The handler rereads the files from disk, so a change made while nobody watched decides. Times missed while the machine slept or was off run once on wake, as `caught-up` with the missed times. A run whose previous one still runs or waits on a person is recorded as `skipped`, never queued. Resuming owes the next time from now. Daylight saving follows the wall clock of the machine's time zone: a skipped time runs after the skip, a doubled one runs once.
- An agent run is a hidden agent chat of the project, opened by `routine:<id>` and started through the outbox like `start-agent`, with the person's mode as ceiling. It is on no canvas and outlives its routine. Its brief tells it to publish a result it keeps to Output under the routine's output key, and nothing when it has none. The daemon gives a version published from that chat `maker: 'routine'` with the routine and run from its own record (`provenanceOf`). A command or launch run delivers its output as a version itself (`Artifacts.deliver`).
- Removing a routine never removes its runs, their chats or its artifact.
- A routine node (kind `routine`) holds only the id of a routine of its own project (`routine`, the last field of `ProjectNodeSchema`). Unlike an artifact's reference, that id travels in the shared file: a shared routine's id names the same routine for a teammate, a private one's names nothing on their machine, and the node says so. A Ruimte older than the kind reads the node as `unknown` and writes it back as it was (`project-split.test.ts`).
- The node draws from the client's routine list and asks the machine nothing itself. A block of its strip opens that run in Routines, since a run's chat is hidden and on no canvas. Beside the node the canvas draws its newest runs, the newest one's chat open, and its Output, derived from that list only (`apps/client/src/routines/RoutineBeside.tsx`). That view is never written to a project and is never a node, so a run's chat stays off every canvas and a teammate sees their own machine's runs.
- `read` of the node prints the routine and its newest runs (`routine-report.ts`). `node new routine --routine` adds one and approves nothing.
- A launch routine starts a launch only as an agent would: when a person approved that launch as it stands now.
- An agent reaches routines only through `ruimte-context routine` (`canvas/routine-verb.ts`, handled in `actions/routine-actions.ts`, through `agent-host.ts`). It lists, adds, edits, pauses and resumes its own project's routines. It runs one now only when a person approved it as it stands (`routine-held` otherwise, `routine-busy` while the previous run goes on). Every add or edit goes through `saveByAgent`, so it waits on a person again. No verb approves, declines or removes a routine.
