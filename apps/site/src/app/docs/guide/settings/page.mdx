# Settings

<p className="lead">Settings hold what differs per person or per machine: the theme, your keys, the agent CLIs and what agents may do.</p>

Press <Shortcut keys="Mod+," /> to open Settings, and <Shortcut keys="Mod+F" /> inside to search them. Some settings belong to a machine: they apply to every device connected to it, and the page says so.

## Accounts

Settings, Providers lists the accounts of each CLI. An extra Claude Code account signs in and keeps its history apart from your default account, so it starts without the instructions, skills, agents and commands you set up there.

Open the extra account and turn on **Use the setup of the default account**. Its chats and terminals then read `CLAUDE.md`, the rules, skills, agents and commands of the default account, and a change there shows in both. Your permissions, hooks, model, status line and output style are copied once. After that the extra account keeps its own.

Sign-in and history stay apart. A file the extra account already holds stays as it is, and the page names what stayed. A chat that is already running picks the setup up when it starts again. Turning the switch off removes the links and leaves the copied settings in place.

## Text model

Ruimte asks a model for short texts: the title of a new chat, a commit message and a proposal for a merge conflict. **Text model** under Settings, Agents says which model writes them on a machine. It applies to every project on that machine and to every device connected to it.

**Automatic** leaves the choice to Ruimte, as before. With **Choose** you pick a CLI, a model and, if you have more than one account for that CLI, an account. Without a model, Ruimte uses the cheapest one of that CLI at the CLI's default reasoning.

Ruimte never switches to another CLI for you. If the CLI you chose is signed out, uninstalled or turned off, a request for a commit message fails and says why, and a new chat keeps the title Ruimte made from your first prompt. Pick Automatic to let Ruimte choose again.

The editor's AI features have their own choice, under Settings, Editor, AI. A machine that has not been updated shows the setting as unavailable.

## Language and region

Ruimte speaks English and Dutch. Set the language and the region apart: the language picks the words, the region the order of dates and how numbers are written. The region follows the language unless you set it.

## Usage and models

Usage adds up what your agents cost per model and provider, with the plan limits your CLIs report. **Compare models**, in the command palette, compares models on intelligence, coding, agentic work, cost and speed.

## Processes

The Processes panel shows the CPU and memory of each terminal and agent. A process that seems stuck gets a warning. Ruimte stops a process only when you click the button.
