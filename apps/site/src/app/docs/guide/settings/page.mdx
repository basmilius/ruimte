# Settings

<p className="lead">Settings cover what differs per person or per machine, such as the theme, your keys, the agent CLIs and what agents may do. Everything else works one way, without a setting.</p>

Open Settings with `Cmd+,`. Inside, `Cmd+F` searches every setting. Some settings belong to a machine rather than to you: they apply to every device connected to that machine, and the page says so.

## General

Ruimte is in English and Dutch. You set the language and the region apart. The language picks the words, and the region picks the order of dates and how numbers are written.

General also decides whether projects show as tabs or in a menu, which projects the sidebar and Needs you cover, when the dock under a canvas shows, and where browsing for a folder starts.

## Appearance

Light, dark or system, a palette and an accent color. Themes from extensions sit beside them. Also the interface font and its size, the panel layout, and a glow in the project's color.

## Keyboard

Every shortcut, by area. See [Keyboard shortcuts](/docs/guide/shortcuts).

## Workspace

- **Views.** The size new nodes start at, the canvas map, how far the canvas draws ahead, snapping in drawings, and swiping between pages in a browser.
- **Editor.** Font, display, folding, smart keys, saving, code vision, live templates, language servers and the AI features.
- **Terminal.** Font, where links open, and on Windows the shell a new terminal opens in.
- **Files and Git.** How files open, hidden and ignored files, the diff layout, and the worktree folder.
- **Extensions.** What you added to Ruimte, and the store. See [Extensions](/docs/extensions).

## AI

- **Providers.** Each agent CLI with its accounts, login state and default model. Add a second account of a CLI, install a CLI, or add a provider from the registry. API keys for the Claude API and NanoGPT go here too.
- **Chats.** How replies appear, the reading width, the key that sends, what an agent may show, and maps.
- **Agents.** Defaults for new agents, what agents may do on each machine, agent status in terminals, notifications, keep awake and computer use.
- **Voice.** Microphone, Speech to text and Voice Control. See [Voice](/docs/guide/voice).
- **Usage.** Costs, tokens and plan limits, across models and providers.

## About and Account

**About** shows the version, the machine, its data folder and the update track, and reopens Set up Ruimte. **Account** holds your sign-in and your machines. See [Your account and machines](/docs/guide/machines).

## Usage and models

Usage adds up what your agents cost, per model and provider, with the plan limits your CLIs report. Ruimte never reads your vendor logins to get these numbers. **Compare models** in the command palette compares models on intelligence, coding, agentic work, cost and speed.

The **Processes** panel shows the CPU and memory of each terminal and agent. A process that seems stuck gets a warning there; Ruimte never stops it unless you press the button.
