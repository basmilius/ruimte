# Routines and Output

<p className="lead">A routine runs an agent, a command or a launch at a set time. What agents publish, and what you save from a chat, goes to Output.</p>

## Routines

Press `Cmd+Option+S` to open Routines. It shows the week: what ran, what waits and what comes next, for one project or all of them. Drag across the days to plan a new routine, or click **New routine**.

A routine has a name, a project and what it runs:

- **Agent.** A prompt for an agent of your choice, with its model and permission mode. In the prompt, `/` opens a command, `$` a skill, `@` a file and `#` a view.
- **Command.** A shell command, in a folder of the project.
- **Launch.** One of the project's [launches](/docs/guide/launches).

It runs once, on chosen days, several times through the day, or on a cron expression such as `0 9 * * 1-5` (weekdays at 09:00). Times follow the clock of the machine. Runs stay at least 15 minutes apart.

**Share with team** puts the routine in the project file your team commits. Otherwise it stays yours.

### Approval

A routine runs only after you approve it as it stands now. When someone changes it, through a teammate's commit, by hand or by an agent, it asks again. Agents can add and change routines in their own project, but never approve one.

### When it runs

- A routine runs on the machine, whether or not the project is open in a window. A computer that sleeps runs nothing; see [Keep the computer awake](/docs/guide/attention#keep-the-computer-awake).
- Times missed while the machine was off or asleep run once when it wakes.
- A run is skipped while the previous run still goes on.
- Pause a routine to stop it. Removing a routine keeps its past runs, their chats and its Output.

An agent's run happens in a chat of its own, out of sight. It ends by publishing its result to Output. Put a routine on a canvas as a node to see its latest runs beside it.

## Output

**Toggle output panel** in the command palette opens Output. It holds what agents published and the pages and images you saved from a chat: reports, images, builds, exports, recordings and pages.

Each item keeps its versions, newest first, with where it came from: the chat, the routine or the machine. Filter by project, kind, source or routine, or search.

- Open an item to view it. A page runs closed off, as in a chat.
- **Copy to project** writes a version into the project folder, as a new file for git.
- **Remove** deletes versions after you confirm. Nothing in Output is deleted on its own, and agents never remove anything.

A design page can be kept here too, with **Save version**.
