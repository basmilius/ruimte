# Routines and Output

<p className="lead">A routine runs an agent, a command or a launch at a set time. Output keeps what agents publish and what you save from a chat.</p>

## Routines

Press <Shortcut keys="Mod+Alt+S" /> to open Routines. The week view shows what ran, what waits and what comes next, for one project or all of them.

### Add a routine

1. Drag across the days, or click **New routine**.
2. Name it, pick the project and choose **What it runs**:
   - **Agent**: a prompt, with the agent, its model and its mode. In the prompt, `/` opens a command, `$` a skill, `@` a file and `#` a view.
   - **Command**: a shell command, in a folder of the project.
   - **Launch**: one of the project's [launches](/docs/guide/launches).
3. Choose **Repeat**: **Once**, **On days**, **Through the day** or **Cron**.
4. Click **Create routine**.

Times follow the clock of the machine. A cron expression has five fields; `0 9 * * 1-5` runs on weekdays at 09:00. Runs stay at least 15 minutes apart.

**Share with team** puts the routine in the project file your team commits.

### Approve a routine

A routine runs only after you approve it as it stands. When it changes, by a teammate's commit, by hand or by an agent, it asks again. Agents can add and change routines in their project but never approve them.

### When a routine runs

- The machine runs it, whether or not the project is open.
- Times missed while the machine was off or asleep run once when it wakes.
- A run is skipped while the previous run still goes on.
- Pause a routine to stop it. Removing it keeps its past runs, their chats and its Output.

<Note>A computer that sleeps runs no routines. See [Keep the computer awake](/docs/guide/attention#keep-the-computer-awake).</Note>

An agent's run happens in a chat of its own, out of sight, and publishes its result to Output. To see a routine's latest runs on a canvas, add it as a routine node.

## Output

Run **Toggle output panel** from the command palette. Output holds what agents published and the pages and images you saved from a chat: reports, images, builds, exports, recordings and pages.

<OutputPanel />

Each item keeps its versions, newest first, with where each came from. Filter by project, kind, source or routine, or search.

| Action | Result |
| --- | --- |
| Open an item | Shows the version. A page runs closed off, as in a chat. |
| Copy to project | Writes the version into the project folder as a new file |
| Remove | Deletes versions after you confirm |

Nothing in Output is deleted by itself, and agents never remove anything. A design page goes to Output with **Save version**.
