# Terminals

<p className="lead">A terminal runs your shell, or an agent CLI in its own interface. It keeps running on the machine when you close the window.</p>

## Open a terminal

Press <Shortcut keys="Alt+T" /> on a canvas, or run **New terminal view** from the command palette. It opens your login shell in the project folder, with 10,000 lines of scrollback.

The screen and scrollback stay when you close the window or open the project on another device. When the shell exits, click **Restart**.

## Run an agent in a terminal

Click a CLI under **Or run** in the terminal on an empty canvas, or run **New Claude Code terminal** (or another CLI) from the command palette. You type, approve and answer in the CLI's own interface.

The header shows the agent's status:

| Status | Meaning |
| --- | --- |
| <StatusPill status="running" /> | The agent works. |
| <StatusPill status="needs-you" /> | The agent asks a question or wants permission, in its own prompt. |
| <StatusPill status="idle" /> | The turn is done. The agent waits for your next message. |
| <StatusPill status="error" /> | The turn ended with an error. |
| <StatusPill status="delegating" /> | The turn is done, but agents it started still work. |
| <StatusPill status="exited" /> | The CLI or shell exited. |

<Note>The status needs Ruimte's lines in the CLI's own settings. Allow them under Settings, Agents, Agent status in terminals. Without them, a terminal agent shows no status and never asks for your attention. Antigravity only reports a finished turn.</Note>

When a terminal agent waits, Ruimte shows a card with **Go to terminal**. You answer in the terminal; Ruimte never answers for you.

After Ruimte or the machine restarts, click **Resume** in an agent's terminal to continue the conversation.

New terminal agents start in the permission mode set under Settings, Agents, Terminal agents start in. See [Permissions](/docs/guide/chats#permissions).

## Links, ports and files

- Hover a link to see its address. <Shortcut keys="Mod" />-click opens it. Settings, Terminal, Open terminal links in chooses **External browser** (the default) or **Ruimte**, which opens a browser node beside the terminal.
- A `localhost` link opens only when the terminal runs on the computer in front of you.
- On macOS and Windows, a terminal shows a badge such as `:5173` for each port its programs listen on. Click it to open the page in a browser node beside the terminal.
- Drop a file on a terminal to type its path.

## Approve a command from a shared view

A terminal in a shared view can carry a start command, such as `bun dev`. On your machine the terminal shows **Run `bun dev`?** and waits until you click **Run**. When someone changes the command, it asks again.
