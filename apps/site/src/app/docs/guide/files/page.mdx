# Files and the editor

<p className="lead">The Files panel shows your project folder. Files open in an editor with language servers, and agents' changes show in the code.</p>

<FilesEditor />

## The Files panel

Click the folder icon in the rail at the right of the window, or run **Toggle files panel**.

- **Filter files** narrows the tree. **Show hidden and ignored files** adds those files to it.
- Right-click a file or folder to create, rename or delete, or to copy its name, path or relative path.
- **Copy mentions** copies the selected files as `@` references for a chat.
- On a Mac, press <Shortcut keys="Space" /> for Quick Look.

## Open a file

- Click it in the Files panel. It opens as a tab or a view.
- Drop it on a canvas to make it a node.
- Press <Shortcut keys="Mod+K" /> and type its name.
- Press <Shortcut keys="Mod+Shift+F" /> to search the text of every file in the folder.

Besides code, Ruimte shows images, PDFs, audio, video, Markdown, HTML pages, tables, 3D models and archives.

## Edit code

The editor uses language servers for TypeScript, Vue, PHP, SQL, CSS, Python and more: completion, problems while you type, go to definition, find usages, rename, code actions, refactorings, organize imports and formatting. **Toggle problems panel** lists the problems of the open files.

| Shortcut | Action |
| --- | --- |
| <Shortcut keys="Mod+F" /> | Find in the file |
| <Shortcut keys="Mod+Shift+H" /> | Find and replace in the file |
| <Shortcut keys="Mod+Alt+L" /> | Format the document |
| <Shortcut keys="Mod+Alt+K" /> | Add the selection to a chat |
| <Shortcut keys="Mod+I" /> | Inline edit |

Settings, Keyboard lists every editor shortcut. Settings, Editor sets the font, display, folding, smart keys, live templates and language servers.

**Code vision** shows above each declaration how often it is used and who last changed it in git. Lines you have not committed have no author. Turn either off under Settings, Editor.

## Work with an agent in the editor

**Add selection to chat** puts the selection in the draft of a linked chat, or a chat you pick. Nothing is sent until you send it.

**Inline edit** asks an agent to change the selection and shows its proposal in place. **Apply** makes the change as one undo step.

When an agent edits a file you have open, Settings, Editor, Agent changes in open files decides what you see:

| Mode | What you see |
| --- | --- |
| Off | Nothing extra |
| Gutter | A mark beside each line an agent changed |
| Review | Each change with **Keep**, **Undo** and **Comment**. An undo or comment becomes a draft for the chat. |

**Next agent change** and **Previous agent change** in the command palette step through the changes.

On a Mac with Apple's on-device model, the editor also explains code, suggests names and suggests code while you type. <Shortcut keys="Tab" /> accepts a suggestion, <Shortcut keys="Alt+]" /> accepts one word, <Shortcut keys="Escape" /> dismisses it. These run on the Mac and never change files by themselves.

## When a file changes on disk

When a file changes on disk while you have unsaved edits, Ruimte merges the changes that do not overlap. For the ones that overlap, choose **Keep yours**, **Keep theirs** or **Keep both**.
