# Install and first project

<p className="lead">Install the app, connect an agent CLI, open a folder and start an agent.</p>

## Install

Download Ruimte from [ruimte.app](/#download). The app updates itself.

| System | Download |
| --- | --- |
| macOS | Disk image, for Apple silicon |
| Linux | AppImage, Debian or RPM package, for x64 and arm64 |
| Windows | Installer, for x64 |

<Note>On Windows, agents and launches run in Git Bash. Install [Git for Windows](https://gitforwindows.org) first.</Note>

To run Ruimte on a server without a screen, see [A machine without a screen](/docs/guide/headless).

## Choose how Ruimte runs

At the first start, choose one:

- **Run agents on this computer.** Projects, terminals and agents run here. You can open them from your other computers and your phone too.
- **Only connect to my machines.** Sign in and open the machines on your account. No agents run on this computer.

Ruimte restarts once. To change this later, open Settings, Account.

## Set up Ruimte

The **Set up Ruimte** list has three tasks. Do them in any order, or later from Settings, About.

1. **How Ruimte works.** A one-minute introduction.
2. **Connect providers.** Ruimte lists the agent CLIs it finds on this computer, such as Claude Code, Codex, GitHub Copilot, Grok and Antigravity. Logging in to a CLI opens a terminal where the CLI asks for your login. You need one logged-in CLI to start.
3. **Computer use.** Optional, on a Mac. See [Computer use](/docs/guide/computer-use).

Ruimte then asks to add a few lines to each CLI's settings, which also apply outside Ruimte. Choose **Allow** to see in a terminal whether its agent works, is done or waits for you. Change it later under Settings, Agents, Agent status in terminals.

To install another CLI, open Settings, Providers. It shows the install command and can run it in a terminal.

## Open a project

1. On the start screen, click **Open folder**.
2. Pick the folder of something you work on.

Or press <Shortcut keys="Mod+K" /> and type a path, such as `~/projects/shop`. A path that does not exist yet creates the folder.

Ruimte adds a `.ruimte` folder to the project and asks what you want to start with.

## Start an agent

An empty canvas lists what you can add:

| Section | What it adds |
| --- | --- |
| Agents | A chat or a terminal for each agent CLI on this machine |
| Add | A shell, a web page, a note or a group |
| From project | A file, a drawing, a diagram or a saved layout |

Click **Chat** under Agents for a conversation Ruimte draws, or **Terminal** for the CLI's own interface. [AI chats](/docs/guide/chats#chat-or-terminal) compares the two.
