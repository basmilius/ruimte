# Install and first project

<p className="lead">Install the app, connect an agent CLI, open a folder and start an agent.</p>

## Install

Download Ruimte from [ruimte.app](/#download). The app updates itself.

| System | Download |
| --- | --- |
| macOS | Disk image, for Apple silicon |
| Linux | AppImage, Debian or RPM package, for x64 and arm64 |
| Windows | Installer, for x64 |

<Note>On Windows, agents and launches run in Git Bash. Install [Git for Windows](https://gitforwindows.org) first.</Note>

For a server without a screen, see [A machine without a screen](/docs/guide/headless).

## Choose how Ruimte runs

At the first start, choose one:

- **Run agents on this computer.** Projects, terminals and agents run here. You can also open them from your other computers and your phone.
- **Only connect to my machines.** Sign in and open the machines on your account. No agents run on this computer.

Ruimte restarts once. Change it later under Settings, Account.

## Set up Ruimte

**Set up Ruimte** lists three tasks. Do them in any order, or later from Settings, About.

1. **How Ruimte works.** A one-minute introduction.
2. **Connect providers.** Lists the agent CLIs Ruimte found, such as Claude Code, Codex, GitHub Copilot, Grok and Antigravity. Logging in opens a terminal where the CLI asks for your login. You need one logged-in CLI.
3. **Computer use.** Optional, on a Mac. See [Computer use](/docs/guide/computer-use).

Ruimte then asks to add a few lines to each CLI's settings, which also apply outside Ruimte. Choose **Allow** to see whether a terminal agent works, is done or waits for you. Change it later under Settings, Agents, Agent status in terminals.

To install another CLI, open Settings, Providers. A CLI that is not installed shows its install command and **Run in a terminal**.

## Open a project

1. On the start screen, click **Open folder**.
2. Pick the folder of something you work on.

Or press <Shortcut keys="Mod+K" /> and type a path, such as `~/projects/shop`. For a folder that does not exist yet, **Create and open** creates it.

Ruimte adds a `.ruimte` folder to the project and asks what you want to start with.

## Start an agent

An empty canvas shows dashed outlines of a chat, a terminal, a browser and a note. Click one to add it.

<EmptyCanvas />

Under **Pick an agent to start**, click a CLI for a conversation Ruimte draws. Under **Or run** in the terminal, click a CLI for its own interface in a terminal. [AI chats](/docs/guide/chats#chat-or-terminal) compares the two.

A click on the chat outline itself starts the CLI you used last. Files, groups, text, layouts and drawings are a right-click or <Shortcut keys="Mod+K" /> away.
