# Keyboard shortcuts

<p className="lead">The shortcuts you use most, in the keys of your own keyboard. Settings, Keyboard lists them all, by area.</p>

Every shortcut uses a modifier key, so typing never sets one off. The exceptions are a drawing's tools while you are not typing, the keys inside a question card, and <Shortcut keys="Space" /> for Quick Look in the Files panel on a Mac.

## Window

| Shortcut | Action |
| --- | --- |
| <Shortcut keys="Mod+K" /> | Command palette |
| <Shortcut keys="Mod+Shift+F" /> | Find in files |
| <Shortcut keys="Mod+," /> | Settings |
| <Shortcut keys="Mod+B" /> | Show or hide the sidebar |
| <Shortcut keys="Mod+Shift+N" /> | New window |
| <Shortcut keys="Mod+Alt+N" /> | New chat |

## Views and cells

| Shortcut | Action |
| --- | --- |
| <Shortcut keys="Mod+T" /> | New view |
| <Shortcut keys="Mod+1" /> to <Shortcut keys="Mod+9" /> | Open a view of the sidebar |
| <Shortcut keys="Mod+Shift+[" />, <Shortcut keys="Mod+Shift+]" /> | Previous, next view |
| <Shortcut keys="Mod+\" /> | Split right |
| <Shortcut keys="Mod+Shift+\" /> | Split down |
| <Shortcut keys="Mod+Shift+Enter" /> | Maximize or restore the cell |
| <Shortcut keys="Mod+W" /> | Close the cell |
| <Shortcut keys="Ctrl+Tab" />, <Shortcut keys="Ctrl+Shift+Tab" /> | Next, previous tab |
| <Shortcut keys="Mod+Alt+Shift+ArrowLeft" />, <Shortcut keys="Mod+Alt+Shift+ArrowRight" /> | Move the tab |
| <Shortcut keys="Mod+Alt+ArrowLeft" /> and the other arrows | Focus the neighboring cell |
