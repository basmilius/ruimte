# Keyboard shortcuts

<p className="lead">The shortcuts you use most. Settings, Keyboard lists all of them, by area.</p>

This page writes them the way a Mac does. On Windows and Linux, use `Ctrl` where it says `Cmd` and `Alt` where it says `Option`.

Every shortcut uses a modifier key, so typing never sets one off by accident. The exceptions are the tools of a drawing while you are not typing, the keys inside a question card, and `Space` for Quick Look in the Files panel on a Mac.

## Window

| Shortcut | What it does |
| --- | --- |
| `Cmd+K` | Command palette: jump to anything, run a command, open a folder |
| `Cmd+Shift+F` | Find in files |
| `Cmd+,` | Settings |
| `Cmd+B` | Show or hide the sidebar |
| `Cmd+Shift+N` | New window |
| `Cmd+Option+N` | New chat |

## Views and cells

| Shortcut | What it does |
| --- | --- |
| `Cmd+T` | New view |
| `Cmd+1` to `Cmd+9` | Open a view from the sidebar |
| `Cmd+Shift+[` and `Cmd+Shift+]` | Previous and next view |
| `Cmd+\` | Split right |
| `Cmd+Shift+\` | Split down |
| `Cmd+Shift+Enter` | Maximize or restore the cell |
| `Cmd+W` | Close the cell |
| `Ctrl+Tab` and `Ctrl+Shift+Tab` | Next and previous tab |
| `Cmd+Option+Shift+Left` and `Right` | Move a tab |
| `Cmd+Option+Left`, `Right`, `Up`, `Down` | Move the focus to a neighboring cell |

## Canvas

| Shortcut | What it does |
| --- | --- |
| `Option+T` | New terminal |
| `Option+C` | New chat |
| `Option+B` | New browser |
| `Option+N` | New note |
| `Option+G` | New group |
| `Option+Left`, `Right`, `Up`, `Down` | Select the neighboring node |
| `Cmd+A` | Select all |
| `Cmd+G` | Group the selection |
| `Backspace` | Delete the selection |
| `Cmd+Z` and `Cmd+Shift+Z` | Undo and redo |
| `+` and `-` | Zoom in and out |
| `Cmd+0` | Zoom to 100% |
| `Shift+1` | Zoom to fit everything |
| `Shift+2` | Zoom to the selection |
| `Cmd+Shift+2` | Zoom to the selected node |
| `Cmd+Option+[` and `Cmd+Option+]` | Previous and next camera position |
| `Cmd+[` and `Cmd+]` | Back and forward in a browser |

## Agents

| Shortcut | What it does |
| --- | --- |
| `Cmd+Option+P` | Next node that needs you |
| `Cmd+Option+Shift+P` | Attention queue |
| `Cmd+Shift+P` | Move to the questions and approvals on the canvas |
| `Cmd+Shift+.` and `Cmd+Shift+,` | Raise and lower the reasoning effort |
| `Option+Up` and `Option+Down` | Previous and next message you sent |
| `Cmd+F` | Find in the chat or file |
