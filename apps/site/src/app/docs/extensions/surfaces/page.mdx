# Surfaces

<p className="lead">A surface is a rectangle an extension draws itself: a panel, a view, a node, a card, an overlay or a viewer.</p>

<Surfaces />

Every surface takes its component as a lazy import, `() => import('./Panel')`, so its code loads when a person opens it. A surface that throws shows the error in its own rectangle; the rest of Ruimte goes on.

Instead of `component`, a surface can name a `frame`. That is an HTML file in your pack, which runs sandboxed with an origin of its own and no storage. It reaches only the hosts the manifest names as `net:` permissions, such as `"net:api.example.com"`, over HTTPS.

<Note>A `frame` surface works in the desktop app only.</Note>

```ts
definePanel({
    id: 'frame',
    title: 'Report',
    icon: 'frame',
    frame: 'views/report.html'
});
```

The frame calls your server part by posting a message to its parent, and gets the answer the same way:

```ts
parent.postMessage(
    {
        ruimte: 1,
        method: 'summary',
        args: []
    },
    '*'
);

window.addEventListener('message', (event) => {
    if (event.data?.ruimte === 1) {
        console.log(event.data.error ?? event.data.result);
    }
});
```

## Panels

A panel opens from the rail on the right, like Ruimte's own Files and Git panels.

```ts
const panel = definePanel<{ chatId: string }>({
    id: 'review',
    title: 'Review',
    icon: 'list-checks',
    component: () => import('./ReviewPanel')
});

panel.open({ chatId: 'chat-1' });
panel.setBadge('3');
```

The component gets `params`, the value the panel was last opened with. The toggle in the rail shows your `icon`, and the badge you set shows on it and after the panel's name:

<RailPanel />

[Open a panel](/docs/extensions/how-to/panel) builds this panel end to end.

## Views

A view fills the window and shows up in the sidebar beside canvases, chats and files. `open(params)` opens it. Its component gets `params` as you passed them, and `undefined` when a person opens it with "New Dashboard" from the palette.

```ts
const dashboard = defineView({
    id: 'dashboard',
    title: 'Dashboard',
    icon: 'gauge',
    component: () => import('./Dashboard')
});
```

## Nodes

A node is a card on the canvas. Its data lives in the project file, so it survives a reload and travels with the project.

```ts
defineNode<{ count: number }>({
    id: 'counter',
    title: 'Counter',
    icon: 'hash',
    size: { width: 320, height: 200 },
    initialData: { count: 0 },
    component: () => import('./Counter')
});
```

```tsx
export default function Counter() {
    const [data, setData] = useNodeData<{ count: number }>();

    return (
        <button onClick={() => setData({ count: data.count + 1 })}>
            {data.count}
        </button>
    );
}
```

A person adds it from the Extensions submenu of the canvas menu, or from the command palette. `addFrom` places that "Add" elsewhere.

<NodeType />

When the shape of the data changes, raise `dataVersion` and give `migrate`, which gets the stored data and its version. [Add a node](/docs/extensions/how-to/node) walks through both.

An agent reads a node of yours along a line once the server part says what it holds. `defineNodeContext` in [The server part](/docs/extensions/server) does that.

## Overlays

An overlay opens your UI over the app. Ruimte draws the header with its title and a close button, and the animation; you draw the body. `open` answers what `close` was given, or `null` when the person dismissed it.

```ts
const rename = defineOverlay<{ name: string }, string>({
    id: 'rename',
    title: 'Rename',
    size: 'sm',
    component: () => import('./Rename')
});

const name = await rename.open({ name: 'Draft' });
```

For a plain question, `host.confirm`, `host.prompt` and `host.pick` ask through Ruimte's own dialogs.

`defineCanvasOverlay` draws over the whole canvas, under Ruimte's own controls. It lets clicks through; set `pointer-events: auto` on what should take them. Neither kind draws while a node is maximized.

With `space: 'canvas'` the overlay draws in the canvas's own coordinates instead, over every node, and pans and zooms with them. A node's `bounds` are then where it stands:

```ts
defineCanvasOverlay({
    id: 'badges',
    space: 'canvas',
    component: () => import('./Badges')
});
```

An overlay on screen can stand on what lies at the bottom of the canvas. Ruimte marks each with `data-canvas-floor`: `ledge` where something may stand on top, such as the dock, and `wall` where it may only walk up to, such as the minimap and a prompt card. Find them from your own element:

```ts
const box = element.closest('[data-canvas-overlay]');
const floors = box?.querySelectorAll('[data-canvas-floor]') ?? [];
```

One that fades away says so in its opacity. These two attributes are part of the API; Ruimte's other classes and attributes are not.

## File and diff viewers

```ts
defineFileViewer({
    id: 'csv',
    title: 'Table',
    extensions: ['csv'],
    component: () => import('./CsvTable')
});

defineDiffViewer({
    id: 'csv',
    title: 'Table diff',
    extensions: ['csv'],
    component: () => import('./CsvDiff')
});

defineFileIcon({
    extensions: ['csv'],
    path: 'assets/csv.svg'
});
```

A viewer opens every file with those extensions, with Ruimte's own view one click away. The file viewer gets `file` with its `text`; the diff viewer gets `file` and the `diff`.

## Languages

`defineLanguage` gives a file type Ruimte does not know its colors in the editor and the viewer:

```ts
defineLanguage({
    id: 'lintel',
    name: 'Lintel',
    extensions: ['lintel'],
    filenames: ['Lintelfile'],
    grammar: 'assets/lintel.tmLanguage.json'
});
```

`grammar` is the path of a TextMate grammar in your pack, as JSON with a `scopeName`, at most 512 KB. Put it under `assets/`, which `pack` copies. Ruimte reads it when the first such file opens. A grammar it cannot read leaves the file plain text, and `ruimte extension dev` prints why.

`extensions` are without the dot, and `filenames` are whole names. `id` is lowercase letters, digits and dashes. It is the name a [language server](/docs/extensions/server#language-servers) of yours lists under `languages`, so the grammar, the server and a `defineFileIcon` for the same extension make a language pack.

A file whose language Ruimte already knows keeps it, and so does a language Ruimte has a grammar for. A grammar stays loaded until the window reloads, so reload after you change one.

This is a [proposed part](/docs/extensions/manifest#proposed-parts): name `languages` under `proposed`. In a test, `host.languageOf(path)` answers the id of your language for a file.

## Marks in the editor's margin

`defineEditorDecoration` puts a mark beside the line numbers of an open file, for coverage or for what a linter found:

```ts
const coverage = defineEditorDecoration({
    id: 'coverage',
    provide: async (file) => {
        const lines = await getServer<Server>().uncovered(file.path);

        return lines.ok
            ? lines.value.map((line) => ({
                  line,
                  kind: 'warning'
              }))
            : [];
    }
});

coverage.refresh();
```

Ruimte calls `provide` when a file opens in an editor, and again for every open file after `refresh()`. A mark names a `line`, counted from 1, an optional `endLine` and a `kind`. The kind is one of `info`, `success`, `warning`, `error` and `muted`, and Ruimte picks the color, so a mark fits both themes. A mark with any other kind or a line below 1 is left out, and a file shows at most 2000 marks of one decoration.

A decoration only reads. `provide` gets the file's `path`, `name` and `extension`, never its text or the selection, and nothing it answers changes the file. Read the text yourself with `files` when you need it. A mark has no hover text yet.

Marks keep their lines while a person types and move with the text. They are yours to refresh after a save, for example from a `files.watch`.

This is a [proposed part](/docs/extensions/manifest#proposed-parts): name `editorDecorations` under `proposed`. In a test, `host.openEditor(path)` opens a file as an editor would, and its `decorations()` are what the margin shows.
