# The server part

<p className="lead">`server/index.ts` runs as one process on the machine, as the person who runs Ruimte. Use it for work that should go on without a window, or needs the machine itself.</p>

Ruimte starts it on the first call from a client, and stops it with the machine. A crash starts it again on the next call; after three crashes in a row, Settings marks it as crashed until the person turns it on again.

## What clients call

The default export lists what a client may call. Every method is async, and its arguments and answer must survive JSON.

```ts
import { defineServer, storage } from '@ruimte/extension/server';

const api = defineServer({
    async count() {
        const next = ((await storage.get<number>('count')) ?? 0) + 1;
        await storage.set('count', next);
        return next;
    }
});

export type Api = typeof api;
export default api;
```

In the client, `useServer<Api>()` makes those methods typed. [Server and secrets](/docs/extensions/how-to/server) builds a panel on a server part that calls an outside service with a stored key:

## Events

`emit(name, payload)` tells every client of the machine, where `useServerEvent(name, listener)` hears it. `onEvent(name, listener)` follows the machine's own events, such as `chat.status`. To follow them while no client is open, set `"autostart": true` in the manifest.

## Storage and secrets

`storage` keeps JSON per extension on the machine. `secrets` keeps strings in a file only the person who runs the machine can read, such as an API key.

`machine.dataFolder` is a folder of the extension's own for anything bigger.

## On a clock

With the permission `clock`, `schedule` runs work every so often, at least every 10 seconds:

```ts
schedule({
    id: 'sync',
    every: '5m',
    run: () => sync()
});
```

## What agents read of your nodes

`defineNodeContext` tells agents what a node of yours holds, also when no client is open:

```ts
defineNodeContext<{ items: string[] }>('checklist', (node) => [
    { text: node.data.items.join('\n') }
]);
```

## Agents and chats

`agents.run` runs a hidden prompt, and `agents.start` a chat a person sees in the project you name. `chats.list` and `chats.send` work as in the client, and `chats.send` stops at 20 messages per chat per hour, so a loop with a chat ends on its own. `defineAgentTool` is described in [Chats and agents](/docs/extensions/chats-and-agents#tools-for-agents).

## The machine's actions

`machine.run(projectId, action, input)` calls a machine action, such as `launch.start`, with the same permissions as in [the client](/docs/extensions/machine#what-the-machine-runs).

## Language servers

With `languages.servers`, an extension adds a language server for a language Ruimte does not know:

```ts
await defineLanguageServer({
    name: 'Zig',
    command: 'zls',
    languages: ['zig'],
    patterns: ['*.zig']
});
```

It shows in Settings like one the person added and starts without asking, since installing the extension was the approval. Calling it again with the same name changes it, and removing the extension removes it, unless the person edited it. It rejects when `command` is not on the machine.

## Logging

`log.info` and `log.error` write to the extension's log, which `ruimte extension logs` prints. While `ruimte extension dev` runs, `console.*` goes to your terminal as well.
