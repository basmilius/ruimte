# Getting started

<p className="lead">From an empty folder to an extension running in Ruimte, with a panel and a server part.</p>

You need [Bun](https://bun.sh) and Ruimte running on the same computer.

## Create the project

```bash
bunx ruimte extension create
```

It asks for a name, an id, the parts you want and a first surface, then writes a project that builds. Pass `--yes` with `--name`, `--id`, `--parts` and `--surface` to skip the questions.

The id is who made it and what it is, joined by a dot: `acme.standup`. Once people install the extension, the id never changes.

## Run it while you work

```bash
bun run dev
```

`dev` builds on every save and reloads the extension in the running Ruimte. It prints `console.*` and `log` from the server part, `console.*` from the client part marked `[client]`, and every action or surface that failed. Pass `--port` when your Ruimte listens on another port.

<DevLog />

Your extension shows under Settings, Extensions, in the In development group. While `dev` runs, "Show extension slots" in the command palette outlines every place an extension can add to.

## The client part

`client/index.ts` runs when the extension loads and calls `define*` functions. A surface is always a lazy import, so its code loads only when a person opens it:

```ts
import { definePanel } from '@ruimte/extension/client';

definePanel({
    id: 'main',
    title: 'Standup',
    icon: 'calendar',
    component: () => import('./Main')
});
```

```tsx
import { useServer } from '@ruimte/extension/client';
import type server from '../server';

export default function Main() {
    const greeting = useServer<typeof server>().greeting.use();

    return <p>{greeting.ok ? greeting.value : greeting.error.message}</p>;
}
```

`icon` names a [Lucide](https://lucide.dev/icons) icon. Without one, the panel shows your extension's mark.

## The server part

`server/index.ts` exports what the client can call. Ruimte starts it on the first call, and again after a crash.

```ts
import { defineServer } from '@ruimte/extension/server';

export default defineServer({
    async greeting() {
        return 'Good morning';
    }
});
```

`useServer().greeting()` returns a promise of a `Result`. `.use()` suspends the component until the answer arrives, so you need no loading state of your own. When the method throws, or the server part cannot run, `ok` is false and `error.message` says why.

## Pack it

```bash
bun run pack
```

`pack` builds a `.rex` file, the form you share an extension in. It checks your icon and themes, and refuses a client part that imports from `server/`.

To install a `.rex`, open Settings, Extensions, Browse store and press "Install from file…". Ruimte shows its name and what it asks for before anything runs.
