Voorbereiding

  1. Start de desktop-app vanuit de root van de repository met bun dev. De daemon draait dan op poort 4211 met RUIMTE_HOME op ~/.ruimte-dev, los van een geïnstalleerde Ruimte.
  2. Maak een los project dat een git-repository is, zodat samenvoegen nooit de repository van Ruimte raakt. Bijvoorbeeld: 
    mkdir -p ~/Development/Projects/ruimte-proef/orchestratie-test
cd ~/Development/Projects/ruimte-proef
git init -b main
echo "regel 1" > orchestratie-test/gedeeld.txt
git add -A && git commit -m "test: start"
    Open die map als project in Ruimte. gedeeld.txt moet gecommit zijn vóór een --worktree-test, anders ziet elke worktree hem niet.
  3. Zorg dat claude en codex in een terminal ingelogd zijn. Aftakken naar een andere CLI en de teams gebruiken allebei.
  4. Zet de nieuwste build op iPhone en iPad en koppel ze aan de machine waarop je test. Voor de dev-daemon: bun src/main.ts pair --port 4211 in apps/server.
  5. Houd een tweede client bij de hand voor de test met twee clients (een tweede venster, station of de iPhone).

Opruimen na afloop

Niets verwijdert een worktree vanzelf, ook niet na een merge. Ruim ze op in het git-paneel, sectie Worktrees, met "Remove..." per rij of "Remove worktrees..." in het menu van een teamgroep. Wat daarna nog over is, haal je met git weg. De worktrees van de dev-daemon staan onder ~/.ruimte-dev/worktrees.

cd ~/Development/Projects/ruimte-proef
git worktree list
git worktree remove --force <pad>
git branch -D <branch>
git worktree prune

Bewust niet gebouwd

Dit ligt voor later. Test er niet op; dat het ontbreekt is geen bevinding.

  • Worktrees op iOS: de app toont geen sectie, geen merge en geen verwijderen.
  • Een merge in een branch die nergens uitgecheckt is, als merge op alleen de ref. Die wordt nu geweigerd, met "Merge into <branch>" als uitweg.
  • Wijzigingen die buiten Ruimte in een worktree gebeuren, verschijnen pas na verversen of focus op het paneel, niet live.
  • "Restore files to this turn" als eigen actie op een turn.
  • "Retry" die een bericht terugzet in de composer.
  • Een verb waarmee agents zelf aftakken.
