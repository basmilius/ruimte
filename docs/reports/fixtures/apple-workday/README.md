# Werkdag: website Studio Noord

Dit is een fictieve oefencase voor dagelijks projectwerk. Alle personen en afspraken zijn verzonnen.

Je helpt een klein team met de voorbereiding van een klantoverleg over een website.
Lees de overlegnotities, de recentere klantmail en de bestaande planning. De bestanden kunnen elkaar tegenspreken; let op datum, bron en wat nog niet bevestigd is.

## Bestanden

- `overlegnotities.md`: interne aantekeningen van het vorige overleg.
- `klantmail.md`: de recentste reactie van de klant.
- `planning.md`: een verouderd werkdocument dat bijgewerkt moet worden.

Werk alleen in deze projectmap. Bewaar de bronbestanden. Een conceptbericht is een lokaal document; verstuur niets.
