## Persistence and restart

- endpoint.json and PKCS#8 keys: same identity across both implementations.
- auth.json, local.key and file permissions: no unauthenticated loopback shortcut.
- projects index/project/local state and unknown nodes/views; rev conflict and corrupt recovery.
- drawings/diagrams and project icons.
- sessions snapshots and agent resumes; persisted output is not a live shell after restart.
- chat records/logs/attachments/seq, queued messages, interruption resume, checkpoints, forks and summaries.
- pending prompts, lineage, notices, tasks, durable outbox and crash windows without duplicate starts.
- plans, usage index and limits; old/new disk compatibility and atomic updates.

- WebSocket and WebRTC DataChannel share validation/auth/event behavior.
- Broker signaling, reconnect, signed statements, expiration/revocation and TURN safeguards.
- Fragmentation, queue bounds, slow-client resync and connection teardown.
- Separate development home, daemon/client ports and Electron profile.
- The macOS native bundle carries simulator assets only. Physical transport is linked into `ruimte` and self-spawns through a hidden internal command, so service installation has no separate physical bridge artifact. Physical streaming was checked on an iPhone 18 Pro Max before the crate split; physical HID remains untested.
- Linux and macOS native behavior and fixture-tested systemd/launchd lifecycle. The desktop and npm packaging paths consume complete native bundles. Real service installation, distribution signing and notarization were not exercised.
